# Hybrid 결과 분석

Baseline(벡터 검색)에 BM25 키워드 검색을 더하고, 두 결과를 RRF(Reciprocal Rank Fusion)로 합쳤다. 청킹, 프롬프트, 모델, 평가셋은 Baseline과 같다. 문항별 비교는 `../evaluation.md` 참고.

## 구현

- BM25 토큰화: kiwipiepy 형태소 분석으로 내용어(명사, 동사·형용사 어간, 숫자 등)만 남긴다. "제13조", "제24조의2", "별표1"은 형태소 분석이 쪼개므로 통째로 된 토큰을 하나 더 추가한다.
- BM25 인덱스는 기관별로 따로 만든다. BM25에는 필터 기능이 없어서 기관을 섞지 않으려면 인덱스를 나눠야 한다. 측정 결과 다른 기관 문서 혼입은 0건이다.
- 각 검색기에서 후보 20개를 가져와 RRF(k=60)로 합친 뒤 상위 4개를 쓴다. 두 검색기의 가중치는 같다.

## 결과 요약

| 지표 | Baseline | Hybrid |
|---|---|---|
| Hit Rate@4 | 61% | 61% |
| MRR | 0.43 | 0.46 |
| LLM 채점 정답 | 44% | 44% |

전체 수치는 같지만 **5문항을 새로 찾고 5문항을 새로 놓쳐서 상쇄**된 결과다.

| Q14 | 여비규정 제13조 내용은? | "제13조" 토큰으로 p.3이 2위. 오답 → 부분정답 |

## 새로 놓친 문항 (표·구어체 질문)

| ID | 질문 | 원인 |
|---|---|---|
| Q08 | 출장 가면 밥값 따로 나와? | "밥값"은 규정에 없는 단어라 BM25가 "출장"에만 반응했다. "출장, 일비, 식비"가 반복되는 **별지 서식(빈 양식) 페이지 p.20/22/23**이 상위로 올라와 본문 p.3을 밀어냈다. |
| Q18 | 가족수당으로 배우자는 얼마? | 별표3(p.12)은 표가 텍스트로 풀리면서 단어가 흩어져 BM25 점수가 낮다. 벡터 검색 4위였던 것이 밀려났다. |
| Q23 | 국외출장 시 직원의 항공 좌석 등급은? | 별표3(p.15)이 같은 이유로 밀려나고 별지 서식이 들어왔다. |
| Q10 | 할머니 돌아가시면 며칠 쉴 수 있어? | "할머니"는 규정 용어(조부모)가 아니다. BM25가 다른 규정(임원추천위원회, 이사회)을 끌어왔다. |
| Q07 | 퇴직금은 어떻게 계산하나? | "퇴직금"이 여러 규정에 반복되어 직원연봉보수규정, 인사규정이 섞였다. |

## 관찰

- BM25는 **규정 원문의 단어를 그대로 쓴 질문**(조문번호, 정식 용어)에 효과가 있다. 조문번호 유형 hit가 1/4 → 2/4, 상위법 2/3 → 3/3으로 올랐다.
- 반대로 **원문에 없는 단어를 쓴 구어체 질문**과 **표(별표) 페이지**에서는 오히려 방해가 됐다.
- 별지 서식(빈 양식) 페이지는 같은 단어가 반복되어 BM25에서 과대평가된다. 답변에 쓸 내용이 없는 페이지다.
- 두 검색기 가중치가 같아서, 벡터 검색만 잘 찾던 결과가 BM25 노이즈에 밀려나는 경우가 있다.
