# 상위 법령 재검색 v2 (답변 기반 조회) 결과 분석

`structured_hybrid_law`(v1)의 조회 조건을 바꿨다. 비교 기준은 `structured_hybrid`다.

| | v1 | v2 |
|---|---|---|
| 조회 조건 | 답변 전에 LLM이 "규정 발췌만으로 충분한가"를 판단 | 규정만으로 먼저 답한 뒤, **답변이나 답변이 인용한 조문이 법령에 넘기면** 조회 |
| 후보 출처 | 규정 발췌 전체 | 답변 본문 + 답변이 출처로 인용한 조문 (인용 조문은 "준용·따른다·정하는 대로"가 붙은 법령만) |
| 법령을 안 쓰는 질문 | 법령용 답변 프롬프트로 답함 | **기존 답변 그대로** |

조문 선택(법령 목차를 보고 고르기)과 두 단계 추적(법령 → 법령)은 v1과 같다.

## 결과 요약

| 지표 | structured_hybrid | v1 | **v2** |
|---|---|---|---|
| key_facts 통과 | 48% | 55% | **58%** |
| 출처 조문 정확도 | 63% | 58% | 63% |
| LLM 채점 정답 | 50% | 58% | **61%** |
| 잘못된 거절 | 18% | 21% | 18% |
| 상위법 정답 | 0/3 | 1/3 | **3/3** |

## 법령을 조회한 문항 (4개)

| ID | 질문 | structured_hybrid → v2 | 조회한 조문 |
|---|---|---|---|
| Q34 | 출산휴가는 며칠? | 부분정답 → **정답** | 근로기준법 제74조 (90일, 미숙아 100일, 다태아 120일) |
| Q35 | 사망 시 퇴직금은 누가 받아? | 부분정답 → **정답** | 근로기준법 시행령 제48조 (유족 순위) |
| Q36 | 퇴직금 법적 최소 기준은? | 부분정답 → **정답** | 근로기준법 제34조 → 근로자퇴직급여 보장법 제9조·제15조 |
| Q28 | 결혼휴가와 배우자 출산휴가 | 정답 → 정답 | 근로기준법 제74조 (불필요한 조회였지만 답은 그대로 맞음) |

- **Q35는 v1에서 실패하고 v2에서 성공했다.** 답변은 "유족에게 지급"까지만 썼지만, 답변이 인용한 직원연봉보수규정 제36조에 "근로기준법 시행령 제48조를 준용"이 있어서 후보로 잡혔다.
- **Q34는 v1의 실패 원인(유산·사산휴가 일수와 혼동)이 사라졌다.** "충분한가"를 판단하는 단계 자체가 없기 때문이다.
- Q36은 이번 측정에서 제8조 대신 제15조(급여수준: "1년에 대하여 30일분 이상의 평균임금")를 골랐고, 같은 기준이 들어 있어 정답이 됐다. 조문 선택은 여전히 실행마다 달라질 수 있다.

## 법령 없이 채점이 바뀐 문항 (2개)

| ID | 변화 | 원인 |
|---|---|---|
| Q22 | 부분정답 → 정답 | 같은 프롬프트인데 답변 문장이 달라짐 (생성 변동) |
| Q25 | 오답 → 부분정답 | 답변이 완전히 같은데 채점만 달라짐 (채점 변동) |

v1에서는 법령을 안 쓴 문항 4개가 바뀌었고, 그중 일부는 프롬프트가 달라서였다. v2는 법령을 안 쓰면 기존 프롬프트로 답하기 때문에, 남은 차이는 생성·채점 변동뿐이다.

## 해석

- LLM 정답 50% → 61%(+4문항) 중 **법령 조회의 효과는 상위법 3문항**이고, 나머지 1문항(Q22)은 생성 변동이다.
- 조회가 일어난 질문은 36개 중 4개다. 법령이 언급되지 않은 질문은 추가 비용 없이 기존 답변을 그대로 쓴다.
- 불필요한 조회는 1건(Q28)이었고 답에는 영향이 없었다.
- **한계:** 상위법 문항이 3개뿐이라 3/3을 일반적인 성공률로 보기는 어렵다. 조문 선택(특히 Q36의 제8조/제9조/제15조)이 실행마다 달라진다.
