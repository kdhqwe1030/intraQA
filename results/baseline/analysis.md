# Baseline 문제 분석

측정 결과는 `summary.md`, 문항별 상세는 `details.csv` 참고. (36문항: 답변 가능 33, 문서없음 3)

## 핵심 수치

- 검색 Hit Rate@4 **61%**, MRR 0.43
- LLM 채점 정답 **44%**, key_facts 통과 48%
- 답변 가능한 문항을 "찾을 수 없음"으로 잘못 거절한 비율 **30%** (10/33). 대부분 검색 실패가 원인이다.
- 문서없음 문항 거절 100%. 거절 프롬프트 자체는 잘 동작한다.
- 지어낸 답변(grounded=false) 1건 (Q16, 아래 G 참고)

## 실패 원인 분류

| 원인 | 문항 | 관찰 |
|---|---|---|
| **A. 키워드·조문번호를 못 찾음** | Q14, Q15, Q17, Q04, Q05, Q24 | "제13조", "제24조의2", "휴게시간", "수습"처럼 원문에 그대로 있는 단어인데도 벡터 검색이 부칙이나 다른 규정을 가져왔다. 조문번호 유형은 Hit 25%, 정답 0%. |
| **B. 구어체 표현을 못 찾음** | Q11, Q12, Q13 | 와이프→배우자, "연차 돈으로"→연차휴가보상금, "집에서 일"→재택근무. 규정 용어로 바꾸면 찾을 수 있는 질문들이다. |
| **C. 본문과 별표가 따로 검색됨** | Q08, Q20, Q29 | "일비 얼마"에 제13조 본문(지급 비율)만 오고, 금액이 있는 별표1(25천원)은 빠지거나 하위로 밀렸다. 답변이 비율만 말하고 금액을 빠뜨렸다. |
| **D. 출처 조문번호가 틀림** | Q08, Q26 | 청크에 조문 머리말("제13조(...)")이 없어서 LLM이 다른 조문번호를 지어 붙였다 (제13조 → "제2조", 제24조 → "제5조"). |

## 개선 우선순위

| 순서 | 개선 | 대상 원인 | 기대 효과 |
|---|---|---|---|
| 1 | **BM25 Hybrid** | A (+B 일부) | 실패가 가장 많고 조문번호 유형이 사실상 전부 실패. 규정은 조문번호·고유 용어가 많아 키워드 검색 효과가 클 것 |
| 2 | 조문 구조 기반 청킹 | D, E, C 일부 | 조문 단위로 자르고 규정명·조문번호를 metadata로 붙이면 출처 오류와 페이지 경계 문제가 같이 해결됨. 질문에 규정명이 있으면 그 규정으로 필터하는 방식으로 G도 완화 가능 |
| 3 | Query Rewrite / MultiQuery | B | 구어체를 규정 용어로 바꿈 |
| 4 | 법령 API 조회 (Agentic) | F | 규정이 법령을 인용하면 해당 조문을 조회해 답변에 포함 |

14장 기준으로 한 번에 하나씩 적용하고, 같은 평가셋으로 다시 측정한다. 첫 번째 개선은 **Hybrid**로 한다.

## 평가 방법 메모

- 채점 프롬프트를 한 번 고쳤다. 처음에는 정답이 있는 문항을 거절만 한 답변에 "부분정답"을 주는 경우가 있어서, "답이 있는데 거절하면 무조건 오답", "거절 답변의 grounded는 항상 true" 규칙을 명시했다. 위 수치는 수정 후 기준이다.
- 같은 설정으로 다시 측정해도 LLM 채점이 1~2문항 달라질 수 있다. 개선 전후를 비교할 때는 Hit Rate와 key_facts(기계적 지표)를 함께 본다.
