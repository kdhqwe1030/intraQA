# 구조 기반 청킹 결과 분석

Baseline의 페이지 단위 + 1000자 청킹 대신, 규정 전체를 이어 붙인 뒤 **조문·별표·별지·부칙 단위**로 잘랐다. 각 청크 앞에 `[규정명 장 > 제N조(제목)]` 머리말을 붙이고, 조문번호와 걸친 페이지를 metadata로 남긴다. 문항별 비교는 `../evaluation.md` 참고.

- `structured`: 청킹만 바꿈 (검색은 Baseline과 같은 dense). 14장 "한 가지만 바꾸기" 기준의 비교 대상
- `structured_hybrid`: 구조 청킹 + 개선 1(Hybrid) 조합

## 구현

- 섹션 시작은 줄 맨 앞의 `제N조(제목)`, `제N조 삭제`, `[별표 N]`/`(별표 N)`, `(별지 …)`, `부칙`으로 판단한다. 본문 중간의 "제4조의 규정에 따라" 같은 인용은 줄 맨 앞이 아니어서 걸리지 않는다.
- 쪽 머리말(`5300 직원보수규정`)과 쪽 번호를 지운다. 장·절 제목은 따로 청크로 만들지 않고 이후 조문 머리말에 붙인다.
- 부칙 안의 `제1조(시행일)`은 일반 조문이 아니라 부칙의 일부로 묶는다.
- 1,500자가 넘는 조문은 줄 단위로 나누고, 나눈 조각마다 머리말을 다시 붙인다. 조각마다 실제로 걸친 페이지를 기록한다.
- 결과: 청크 797개(평균 637자) → **1,393개(평균 361자)**. 조문 1,091, 별표 117, 별지 91, 부칙 57, 머리말 37.
- 평가: 청크가 여러 페이지에 걸치면, 걸친 페이지 중 하나라도 정답 페이지이면 hit로 본다.

## 결과 요약

| 지표 | baseline | structured | structured_hybrid |
|---|---|---|---|
| 검색 Hit Rate@4 | 61% | 55% | 58% |
| 검색 MRR | 0.43 | 0.35 | 0.44 |
| **출처 조문 정확도** | 26% | **67%** | 63% |
| LLM 채점 정답 | 44% | 47% | **50%** |
| 잘못된 거절 | 30% | 27% | **18%** |

- **출처 조문 정확도가 26% → 67%로 크게 올랐다.** Baseline에서 제13조 내용을 "제2조"로 표기하던 문제(분석 D)가 청크 머리말로 해결됐다. 답변 텍스트에서 기계적으로 세는 지표라 채점 변동이 없다.
- 검색 Hit Rate는 오히려 내려갔다(61% → 55%). 아래 "놓친 문항" 참고.
- 개선 1과 조합한 `structured_hybrid`는 LLM 정답 50%, 잘못된 거절 18%로 네 실행 중 가장 좋다. 조문번호 hit 3/4, 조건·예외 hit 3/4.

## 출처 조문 정확도 지표

- 평가셋의 `article_no`(예: 제13조, 별표3)가 답변에 들어 있는지 확인한다. 거절한 답변과 조문 라벨이 없는 문항은 제외한다.
- Baseline 분석에서 이미 문제로 정의한 "출처 조문번호가 틀림"을 측정하려고 추가했다. 기존 4개 실행에는 저장된 답변으로 다시 계산했다(LLM 재호출 없음).
- **한계:** 조문번호만 보고 규정명은 보지 않는다. 그래서 Q16처럼 다른 규정의 제8조를 인용해도 맞은 것으로 센다.

| ID | 질문 | 관찰 |
|---|---|---|
| Q06 | 통상근무자 근무시간은? | 정답 페이지(유연근무제운영지침 제5조) 대신 취업규칙 제15조(1일 8시간)를 가져왔다. 답 자체는 맞아서 key_facts 통과. 페이지 라벨 기준으로만 실패 |
| Q07 | 퇴직금은 어떻게 계산하나? | 제21조 대신 제27조(지급액의 계산)를 가져왔다. 질문과 관련 있는 조문이지만 정답 라벨과 다르다 |
| Q09 | 월급날이 언제야? | 직원보수규정 제4조 대신 임원연봉보수규정 등 다른 보수 규정이 올라왔다 |
| Q23 | 국외출장 항공 좌석 등급 | 별표3(p.15)을 놓침 |
| Q26 | 근속연수 늘면 연차도? | 취업규칙 제24조를 놓침 |

- 청크가 작아져서(평균 637자 → 361자) Top-4가 덮는 텍스트 양이 줄었다. 페이지 단위일 때는 한 청크에 여러 조문이 같이 들어 있어서 우연히 맞는 경우가 있었다.
- 명확 유형은 hit가 5/7 → 4/7로 줄었지만 key_facts 7/7, LLM 정답 6/7로 오히려 좋아졌다. 정답 페이지가 아닌 다른 조문에서도 답을 찾는 경우가 있어서, 페이지 기준 hit가 실제 답변 품질을 덜 반영한다.

## 새 실패 유형: 삭제 조문과 비슷한 규정명

- Q16 "직원보수규정 제8조 내용을 알려줘"에서 `직원보수규정시행세칙 제8조 삭제` 청크가 1위로 올라왔고, 답변이 "직원보수규정 제8조는 삭제되었습니다"로 틀렸다.
- 원인 1: 구조 청킹으로 "제N조 삭제" 한 줄짜리 조문이 독립 청크가 됐다(59개). 내용이 없는데 조문번호와 규정명이 머리말에 있어서 조문번호 질문에 강하게 걸린다.
- 원인 2: "직원보수규정"이 "직원보수규정시행세칙"에 그대로 포함되어 있어, 규정명이 달라도 LLM이 같은 규정으로 읽었다.
- Baseline의 규정 혼동(70%와 40%를 섞음)과 형태는 다르지만, **이름이 비슷한 규정을 구분하지 못한다는 같은 문제**다.

## 바뀌지 않은 것

- 상위법 문항은 검색 hit 3/3이지만 답변 정답은 여전히 0/3이다. 법령 내용은 규정에 없다.
- 표현다름 유형은 개선되지 않았다(hit 3/6 → 2/6). 구어체 문제는 청킹으로 해결되지 않는다.
